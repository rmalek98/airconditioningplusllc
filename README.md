# Air Conditioning Plus Cooling & Heating — website

Static website for Air Conditioning Plus Cooling & Heating LLC (Tampa, FL). Served with GitHub Pages from the `main` branch, root folder.

- `index.html` and the folders next to it are the pages (services, service areas, tips, about, contact, privacy).
- `static/` holds the stylesheet and scripts. `sitemap.xml` and `robots.txt` are for search engines.

Live site: https://rmalek98.github.io/airconditioningplusllc/
